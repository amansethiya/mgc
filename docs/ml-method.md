# Machine learning method

Librosa computes 20 MFCC, 12 chroma, spectral centroid, bandwidth, rolloff, zero crossing rate and RMS energy, each aggregated using mean and standard deviation, plus one estimated tempo: 75 values. Audio is decoded, converted to mono and resampled to 22050 Hz. The first 30 seconds are used, with a 5-second minimum. Silence and invalid audio are rejected. Training and inference import the same feature code.

Random Forest uses 300 trees; SVM uses RBF with StandardScaler in a pipeline and probability estimation. The fixed models are fit on training data; validation macro F1 selects the winner; the test set is evaluated only after selection. Metrics classify using probability argmax, matching deployment. Timings in metrics.json measure model fit and model-only probability inference, not audio preprocessing or full request latency. The evaluation also includes confusion matrices and per-class reports. Confidence is a model estimate; calibration has not been validated and out-of-distribution audio is still assigned one of the ten genres.

GTZAN has known issues. The training audit finds unreadable files, class counts and exact decoded analyzed-excerpt duplicates. Artist labels, near-duplicates and mislabeled tracks are not automatically discovered. For a stronger evaluation create a reviewed manifest with columns `path,group,exclude,reason`, e.g. `blues/blues.00000.wav,verified-group-id,0,` (illustrative only; do not use invented group IDs in the final report). Group identifiers must encode connected artist/recording sets, including cross-genre overlaps, and cover all discovered tracks. Mark known bad tracks with exclude=1 and documented reason. The group-aware split holds out two of seven stratified folds (roughly 71/14/14) and checks no group overlap. SVM internal probability fitting uses only training records but its internal calibration folds are not group-aware. Short uploads are supported by the same feature extractor but performance on short clips is not measured by the GTZAN full-excerpt evaluation. Report this limitation. CNN and explicit calibration experiments are optional extensions.
